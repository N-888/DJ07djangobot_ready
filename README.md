# 🤖 Django + Telegram Bot API

## 💎 Что делает проект

Этот проект реализует аккуратную и современную связку **Django API + Telegram-бот**.

Пользователь нажимает `/start` в Telegram, бот отправляет `POST`-запрос в Django API, а Django:

- проверяет входящие данные;
- регистрирует нового пользователя в базе;
- не создает дублей;
- возвращает корректный JSON-ответ;
- сообщает боту, была ли регистрация новой или пользователь уже существует.

После этого бот отправляет человеку красивое сообщение с результатом.

## ✅ Сильные стороны решения

- разделение на независимые части: **Django-сервер** и **Telegram-бот**;
- чистая архитектура без путаницы между Django-приложением и файлом бота;
- хранение секретов в `.env`, а не в коде;
- корректная валидация входящих данных через сериализатор DRF;
- правильные HTTP-статусы: `201` для новой регистрации и `200` для повторного запроса;
- защита от зависания бота за счет `timeout` и `try/except`;
- готовность к масштабированию и дальнейшему добавлению новых команд.
